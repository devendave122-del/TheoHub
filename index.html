About TheoHub

TheoHub is a concept for an SDA-focused study and ministry companion: sermon discovery, the 28 Fundamental Beliefs, an AI-assisted study tool, and a research directory.

Before public launch

  • Replace sample sermons with verified, permission-cleared content.
  • Review all belief summaries against the official statement.
  • Configure the secure TheoAI backend and keep API keys server-side.
  • Configure Supabase authentication and Row Level Security for saved work.
  • Test accessibility, phone layouts, and source links.
Important: This project is an integration-ready starter. Live AI and cloud accounts work only after adding your own service credentials, creating the database table, and deploying the backend. It is not yet a signed Android release.
